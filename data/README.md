# One Browser 数据目录

本目录保存 One Browser 的运行数据。备份、迁移或更换电脑时，请先退出程序，再复制整个 `data` 文件夹。

- `webview2/`：账号、账号与窗口关联、窗口界面设置、主题、插件开关、代理选择及其他 WebView2 本地状态。
- `app.db`：窗口、账号、内核、代理、扩展及程序业务记录。
- `<窗口 UUID>/`：每个 fingerprint-chromium 窗口独立的 Cookie、缓存、登录会话和浏览器设置。
- `backups/`：数据快照和本地备份。
- `logs/`：操作日志、错误日志和生命周期日志；文件日志最长保留30天。
- `extensions/`：已下载并启用的内置扩展。
- `automation/`：自动化脚本、任务状态及产物。

1.8.10 空白便携包不会自动读取 Windows AppData 中的旧窗口。升级时请在退出程序后复制旧版的整个 `data` 文件夹；需要全新开始时，保留本说明并删除 `data` 内其他内容即可。系统日志页只显示当前进程会话，磁盘日志保存在 `logs/app.log`。

此目录可能包含账号密码、Cookie、令牌和浏览器会话。不要上传到 GitHub，也不要发送给他人；`.gitignore` 默认只允许提交本说明文件。
