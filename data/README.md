# One Browser 数据目录

本目录保存 One Browser 的运行数据。备份、迁移或更换电脑时，请先退出程序，再复制整个 `data` 文件夹。

- `webview2/`：账号、账号与窗口关联、窗口界面设置、主题、按窗口插件关联、代理选择及其他 WebView2 本地状态。
- `app.db`：窗口、账号、内核、代理、扩展及程序业务记录。
- `OneBrowser-<窗口名>-<8位永久ID>/`：每个 fingerprint-chromium 窗口独立的 Cookie、缓存、登录会话和浏览器设置。
- `backups/`：数据快照和本地备份。
- `logs/`：操作日志、错误日志和生命周期日志；文件日志最长保留30天。
- `extensions/`：已下载并启用的内置扩展。
- `automation/`：自动化脚本、任务状态及产物。

空白便携包不会自动读取 Windows AppData 中的旧窗口。升级时请在退出程序后复制旧版的整个 `data` 文件夹；需要全新开始时，保留本说明并删除 `data` 内其他内容即可。系统日志页只显示当前进程会话，磁盘日志保存在 `logs/app.log`。

此目录可能包含账号密码、Cookie、令牌和浏览器会话。不要上传到 GitHub，也不要发送给他人；`.gitignore` 默认只允许提交本说明文件。

窗口数据目录统一使用 `OneBrowser-工作窗口-a1b2c3d4` 格式。8 位目录 ID 分配后保持不变，内部仍以完整永久 ID 校验归属。修改窗口名会同步目录名；运行中的目录等待关闭后或下次启动前同步。旧 UUID 目录自动迁移，原有 Cookie、密码和会话保留。名称中的 Windows 非法字符替换为下划线，过长名称截短。请通过软件改名，不要手动移动目录。

1.9 窗口删除与空间优化（2026-10-22）
- 修复行尾删除只修改本地列表的问题：使用永久窗口 ID + Profile ID 调用后端，关闭状态确认后同时永久删除配置和对应目录；浏览器运行或启动中禁止删除。
- 后端独立检查真实进程、完整目录标识、数据根目录和其他窗口/回收站路径重叠；检查失败阻止删除。持久化失败恢复目录，前端仅在成功后移除原窗口对象。
- 高级设置新增“清理遗留窗口”：只列出不在当前列表、仍有后端归属记录的窗口，确认后清理关闭的数据；不自动清理未知目录。
- One Browser 托管插件按 CRX 内容散列共用 data/shared/extension-code 下的代码。更新使用新路径并保留旧代码；各窗口独立保存插件用户数据，迁移后移除原窗口内重复代码。
- 网页磁盘缓存默认设置 64 MB 目标值，保留显式自定义缓存大小；这不是整个数据目录的上限。清除缓存前检查全部浏览器已停止，保留 Cookie、密码及会话。
- Chromium 组件、Widevine、安全列表和优化模型仍独立：没有经过并发更新验证，不将它们硬链接到共享可写目录，也不关闭安全更新。
- 程序版本以当前发布包为准。实际节省量取决于已安装插件及网页使用，未承诺每个窗口从 250 MB 降到某个固定大小。

2.0.4：内置插件默认不加载；只有明确关联的窗口才加载。取消关联不删除插件用户数据，旧书签/插件兼容迁移完成后记录标记，失败可重试。
