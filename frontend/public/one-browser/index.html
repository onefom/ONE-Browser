01开始使用

第一次使用应该如何配置？

先进入「内核管理」下载 fingerprint-chromium Windows x64 内核；然后按需添加账号和代理；最后回到「窗口管理」创建并启动窗口。初始版本不附带内核，可显著减小安装包体积。

如何下载、切换、更新或删除内核？

打开「内核管理」，未安装时点击「下载内核」。安装完成后按钮变为「管理」，可在对话框中选择版本、更新或删除。删除后，依赖该内核的窗口暂时无法启动。

02窗口与账号

如何创建和启动浏览器窗口？

点击右上角「创建窗口」，填写窗口名称，并选择账号、代理、系统和已安装的浏览器内核。启动后默认打开「工作台配置页」和 Google 首页两个标签，每个窗口的 Cookie、缓存和本地存储彼此隔离。

如何添加、登录或切换账号？

在「账号管理」中填写账号名称、密码和备注。点击侧栏底部的头像或名字可打开登录对话框；切换账号时必须再次输入对应密码。未登录时头像为灰色 O，登录后显示账号名称首字母并使用主题色。

账号如何关联到窗口？

创建窗口时，在「账号管理」输入框中选择已有账号或直接输入内容。也可在账号管理中设置关联窗口；备注为自由填写文本。

03代理与插件

支持哪些代理导入方式？

支持 Clash 订阅或 YAML、HTTP / SOCKS5 单层代理，以及两层链式代理。导入成功后，主页代理信息会显示「已开启」，并可在创建窗口时选择节点。

默认插件如何加载？

插件中心默认提供 AdGuard 广告拦截器、篡改猴和 Google 翻译。已启用的插件会在 fingerprint-chromium 窗口启动时自动加载。

04数据与外观

如何备份或恢复个人数据？

点击右上角云端图标可导出 OneBrowser-data.zip，同时会把最新数据快照写入安装目录的 data/backups。点击“打开 Google Drive”会在当前已启动的 One Browser 窗口内打开 Drive，登录后上传该压缩包即可。

系统日志记录哪些内容？

「系统日志」会记录关键操作、编辑、错误和异常，例如添加或删除账号、导入代理、备份、主题保存及页面异常。页面每 3 秒刷新一次，可随时点击「清理日志」清空记录；日志会一并包含在本地数据备份中。

如何更换主题或深色模式？

进入「外观设置」选择预设配色或自定义主色。开启「深色内容区」后，页面、表单、卡片、空状态与对话框会同步切换为高对比深色样式。

05常见问题

为什么窗口无法启动？

请先确认对应浏览器内核已经安装。如果窗口使用代理，也请确认代理已成功导入。在线预览展示完整交互流程，实际启动内核、读取外部订阅和加载扩展需在桌面客户端完成。

为什么看不到刚发布的界面？

浏览器可能仍在使用缓存。请按 Ctrl + F5 强制刷新，或关闭当前标签后重新打开预览地址。
