01开始使用

客户端和浏览器内核分别在哪里更新？

窗口管理页右上角「客户端升级」显示当前版本和 GitHub 最新正式版，每周静默检查一次，也可手动检查。发现新版完整版后点击下载，在系统浏览器中下载压缩包；退出程序并备份 data 后，仅替换 OneBrowser.exe，保留 data、chrome、bin 和 config.yaml。仓库版本较旧时不会提示降级，网络失败也不会显示已是最新。Chrome、Firefox 内核仅在「内核管理 → 管理内核」中分别检查和下载。

如何导入、导出本软件的账号？

进入「账号管理」，点击说明栏右侧「导出账号」，保存为 RAR 账号归档；点击「导入账号」可选择本程序导出的 RAR，或其中的 accounts.json。RAR 使用存储模式，无需安装额外打包软件。资料包含本软件登录账号、密码和备注，文件未加密，请妥善保存。导入会跳过相同资料；ID 冲突且内容不同时新增独立账号，不覆盖现有账号，不自动迁移窗口关联。取消操作不改变资料，格式或校验失败时不导入。账号仅供本软件登录和窗口管理，不会自动登录浏览器中的网站。

第一次使用应该如何配置？

先进入「内核管理」下载 Chrome 或 Firefox Windows x64 内核；然后按需添加账号和代理；最后回到「窗口管理」创建并启动窗口。初始版本不附带内核，可显著减小安装包体积。

如何下载、导入、更新或删除内核？

打开「内核管理」，点击右上角「管理内核」选择 Chrome 或 Firefox，分别检查对应官方发布源并下载 Windows x64 ZIP。新版安装后，已关联窗口继续使用原版本；如需切换，请编辑窗口选择新版内核。删除内核前必须解除所有窗口关联。内核完整性状态检查必要运行文件是否存在且非空，不代表签名或文件内容校验。下载连接中断时会自动重试和断点续传；无法连接 GitHub 时，可使用「导入内核包」或「导入本地内核」。

02窗口与账号

启动日志里的耗时怎么看？哪些项目可以调整？

启动一次后进入「系统日志」，查看「窗口启动耗时」「启动扫描明细」「启动准备明细」「窗口插件准备」和「调试就绪等待」。日志直接显示各步骤的毫秒数：界面不再等待全部窗口的目录同步；桌面端校验当前窗口目录、检查进程，只准备该窗口已关联的插件及代理，再读取会话并启动内核。各明细是嵌套关系，请勿把总计与子步骤相加。可先在插件中心停用不需要的插件，关闭不需要恢复的网页，再复测同一窗口；数据隔离、归属和进程检查不应直接跳过。程序没有为日常启动设置固定5秒等待；残留进程的5秒是处理超时上限，正常路径的稳定确认默认250毫秒，其他自定义值会保留。自动关闭内部新标签页在就绪后后台执行，不阻塞启动返回。

浏览器启动较慢或打开了多余页面，怎么办？

首次启动需要安装内核；仅在选用插件时准备对应插件包，请等待本次下载完成；后续启动可检查所选代理是否可用，并关闭不需要恢复的标签页。若仍较慢，请在「系统日志」查找「窗口启动耗时」或「启动阶段耗时」，导出日志用于排查。新窗口打开工作台和 Google；已有会话时恢复该窗口自己的网页。启动时会清理内部新标签和应用页，网站或插件自己的引导页需自行关闭。

「本月新增」如何计算？为什么有日期未知的窗口？

窗口总数下的「本月」按本机年月统计当前列表中本月创建的窗口，新建及复制后立即更新；改名和修改设置不改变创建日期，删除窗口后不再计入。旧版本没有保存窗口创建日期，无法准确补算，因此显示为「日期未知」且不计入本月；不会把首次启动浏览器的日期当成窗口创建日期。

如何创建、筛选、选择和启动浏览器窗口？

点击右上角「创建窗口」，填写窗口名称，并选择账号、代理、系统和已安装的浏览器内核。窗口较多时，只需在表格区域向下滚动即可查看后续窗口，顶部区域保持固定。主页「筛选」可按内核版本、分组和代理情况组合查询；点击表头左侧复选框可全选或取消全选当前筛选结果，单独勾选时表头会显示半选状态。列表中的系统、网络和加号图标可分别查看窗口配置、出口 IP 与位置、添加或关联账号；点击名称或备注可原位修改，编辑底色会随文字长度平滑伸缩，不会撑满整列或改变文字位置。窗口缩小到应用允许的最小宽度时，列表会压缩列间距、图标间距和操作区，但仍保留全部八列与行尾操作。

如何添加、登录或切换账号？

在「账号管理」中填写账号名称、密码和备注。登录对话框的账号下拉列表可用鼠标滚轮或触控板滚动，查看第九个及后续账号。点击侧栏底部的头像或名字可打开登录对话框；切换账号时必须再次输入对应密码。未登录时头像为灰色 O，登录后显示账号名称首字母并使用主题色。

如何删除窗口和对应数据？

浏览器仍在运行或启动中时不能删除，请先关闭浏览器或点击「停止」。在窗口行尾菜单点击「删除」，确认后会一并删除该窗口配置、Cookie、已保存密码、标签会话和插件数据，无法恢复。后端会再检查真实进程和目录归属，检测失败或目录被占用时保留窗口记录并提示。删除不会影响其他窗口或共享插件代码。旧版本只删除列表记录留下的数据，可在「系统设置 → 高级设置 → 清理遗留窗口」检查：先列出窗口名称，确认后仅清理未运行的遗留窗口；不能确认归属的目录不会自动删除。

每个窗口的数据为什么有几百 MB？如何节省空间？

数据目录包含网页缓存、站点与扩展存储、浏览器组件和模型，不能仅因文件夹同名就共享。浏览器内核共用 chrome 下的程序，托管插件代码共用 data/shared/extension-code；Cookie、密码、历史、会话、Local Storage、IndexedDB、Service Worker 和插件用户数据继续独立。网页磁盘缓存默认设置为 64 MB 目标值（内核实际执行可能有偏差），这不是整个窗口目录的上限。关闭全部浏览器后，可在高级设置点击「清除缓存」移除可重新生成的缓存，不删除登录和会话。WidevineCdm、优化模型、安全列表等组件由各内核维护版本及更新状态，本版保持独立，不整体迁出或禁用安全组件。实际占用取决于插件和网页使用情况。共享代码旧版本暂时保留，避免影响尚未关闭的浏览器。

窗口数据目录如何命名？改名会影响登录数据吗？

目录格式为 OneBrowser-窗口名-8位永久ID，例如 OneBrowser-工作窗口-a1b2c3d4。8位 ID 固定，内部保留完整永久标识用于校验归属。修改窗口名会同步目录名；运行中先保留原路径，关闭后或下次启动前再同步。旧 UUID 目录会自动迁移，Cookie、已保存密码、标签会话和扩展数据保留。Windows 非法字符会替换为下划线，过长名称仅在目录中截短。请在程序中改名，不要手动移动文件夹；升级前请退出程序及浏览器并备份整个 data 文件夹。

关闭浏览器后，标签页和登录状态会保存吗？

程序按永久独立标识管理每个窗口：每个窗口使用自己的浏览器配置、用户数据目录和调试端口。新建、复制、排序或改名不会借用其他窗口的 Cookie、密码或会话；复制窗口仅复制设置，不复制登录数据。同一窗口再次启动时才恢复自己的会话。正常关闭浏览器或点击「停止」后，下次启动同一窗口会恢复上次标签页、窗口位置与尺寸，并继续使用该窗口的 Cookie、站点数据和已保存密码；已有会话不会重复添加工作台和 Google 标签。首次打开仍会显示工作台。网站要求重新验证、主动退出或登录凭据过期时仍需重新登录；密码需在浏览器提示时选择保存。升级前请退出应用和浏览器并备份整个 data 文件夹，勿初始化系统或删除窗口数据。

账号如何关联到窗口？

点击窗口行里的加号选择账号；选择后会显示关联图标，再次打开菜单会看到「已关联」标记，也可以取消关联。账号管理的卡片同步列出该账号关联的窗口名称；同一个账号可以关联多个窗口。窗口改名、重新分配、删除窗口或删除账号时同步更新。创建账号时也可选择已有窗口；未选择则保持未关联。旧版按名称记录的关联会尽量迁移，同名而无法确认的记录需要重新选择。关联图标的浅色底色与账号卡片配色对应；数字账号头像最多显示四位数字，更多数字会缩略。

03代理与插件

系统代理 IP 变化时会提醒吗？

有系统代理窗口运行时，启动窗口后立即建立基准，后台每 60 秒检查其启动时绑定的实际 IPv4 出口；同一路由的多个窗口共用检测，发现新 IP 后间隔 2 秒复核，确认一致后弹出一个提醒，显示新旧 IP、国家及受影响窗口。首次检测只建立基准，网络超时、服务限流和无效响应不会误报为 IP 变化；未处理提醒期间不重复弹窗。点击「继续使用」保留窗口，点击「关闭受影响窗口」仅停止该次提醒中仍在原运行状态的窗口，已重启或新开的窗口不受影响。单独配置代理的窗口不检测。无运行窗口时不请求网络；国家查询失败显示未知地区，关闭前请留意未提交内容。本功能使用 ipify 查询出口，使用 ipwho.is 查询国家，检测不是实时断网保护，变化确认通常需要约 2–65 秒，网络超时或服务不可用时会更久；可在系统日志查看 IPMonitor 记录。

支持哪些代理导入方式？如何选择节点？

支持 Clash 订阅或 YAML、HTTP / SOCKS5 单层代理，以及两层链式代理。点击节点即可选用；再次点击当前节点会取消选择并恢复 Windows 系统代理。节点延迟每 60 秒自动刷新，也可点击「刷新延迟」立即测试；最多并行测试 10 个节点，完成一个就显示一个，无需等待整批结束。首次测速仍可能需要启动代理内核；Timeout 表示当前连接栈、节点或测试目标暂时不可达。

延迟很高或与其他代理软件不同，是测速错误吗？

这里显示节点代理请求测速网站并收到 HTTP 响应的耗时，包含连接、可能的 DNS 查询和服务端响应，不能直接与 TCP Ping 或其他目标的数值比较。先点击「刷新延迟」复测，关闭下载任务，再试其他节点；持续较高时检查线路和代理服务。Timeout 表示测试失败，不代表固定延迟。首次准备代理内核的等待不会直接计入显示的 HTTP 延迟。

插件如何安装到指定窗口？能给多个窗口安装吗？

三款内置插件首次默认关闭，不会在打开程序时自动下载。点击卡片右侧圆点，勾选需要关联的窗口，取消勾选可解除关联，点击「保存关联」；再次打开会显示当前已关联窗口。新建和复制的窗口默认不关联插件。运行中的窗口下次启动生效；需要立即应用时，在弹窗中明确勾选「重新启动有变更的运行窗口」。程序会尝试正常关闭并恢复网页，无法正常关闭时提示手动重启。请先保存网页中的未提交内容。取消弹窗不会改变关联；停用只取消目标窗口的绑定，不删除脚本和插件用户数据。导入CRX/ZIP后同样选择安装窗口。

关联后为什么插件还没显示？

窗口正在运行时，保存的是下次启动的插件配置，不会直接改写正在使用的浏览器偏好。关闭并重新启动所选窗口，或在关联弹窗勾选重启后立即应用。多个窗口可以批量关联及重启；如果部分窗口失败，弹窗会分别显示结果，不会把失败窗口标成已加载。插件包缺失时会按本次选择下载，失败可重试。共享的只是插件程序代码，各窗口的设置、脚本和站点数据继续独立。

04数据与外观

如何备份或恢复个人数据？

点击首页右上角云端图标，会在按钮下方直接显示备份面板；可导出 OneBrowser-data.zip，也可在受管浏览器中打开 Google Drive 后上传。面板不会跳转到新页面，按 Esc 或点击面板外即可关闭。

系统日志保存在哪里？为什么升级后还能看到？

页面只显示当前应用进程的会话日志，并每 3 秒刷新；磁盘日志保存在程序旁的 data/logs/app.log，最多保留 30 天。若把新版解压到旧目录、复制旧版 data 文件夹，或旧程序尚未退出，历史文件与旧进程仍会保留。需要全新环境时，请先退出 One Browser，再将新版解压到新的独立目录；「清空当前列表」只清除当前会话列表，「清理30天以上」清理过期磁盘日志。

如何更换主题、折叠侧栏或迁移配置？

进入「系统设置」可选择预设配色、自定义主色、透明磨砂质感或深色模式；内核图标和默认窗口图标会同步使用当前主题色。侧栏底部的箭头可展开或折叠导航，动画完成前无需重复点击。点击窗口彩色图标可选择跟随主题、预设色或十六进制颜色；「高级设置」提供清除缓存、加载配置、导出配置、清理遗留窗口和初始化系统。

如何上传品牌 Logo？图片无法保存怎么办？

在「系统设置 → 品牌设置」点击「上传 Logo」，选择最大 5 MB 的 JPG、PNG、WebP、GIF、BMP 或 AVIF 图片。拖动图片并调整缩放，确认圆形裁切后点击「保存品牌」。侧栏显示新标识并保留状态小点；点击「恢复默认」再保存可恢复原环形标识。文件过大或格式无法读取时，请转换为较小的 JPG 或 PNG；保存失败时请先导出配置备份，再排查磁盘和存储空间。

高级设置的五个按钮分别做什么？

清除缓存：先关闭全部浏览器，再清理 Chrome 和 Firefox 的临时缓存，保留 Cookie、密码及会话。导出配置：保存窗口、账号、主题等界面配置为 JSON；包含账号密码，文件未加密，请妥善保管。加载配置：先关闭全部浏览器，再选择本程序导出的 JSON，取消或文件无效不会更改当前设置；导入不携带其他电脑的浏览器数据绑定，不会迁移 Cookie、网页会话、浏览器内核或插件文件，完整迁移仍需备份相应目录。清理遗留窗口：先扫描并列出不在当前列表的窗口，二次确认后删除，运行中的窗口不会清理。初始化系统：先关闭全部浏览器，勾选确认后清除业务数据并恢复界面设置，保留内核；此操作无法撤销。

05常见问题

修改操作系统后，如何确认指纹生效？

保存窗口设置后，点击齿轮重启窗口。系统选项会传入内核，工作台同步显示目标系统和实际内核类型。支持 Windows、macOS、Linux 的基础系统信息伪装，但不会改变 Windows 宿主系统，也不保证 GPU、Canvas 等全部硬件特征与目标设备一致。自定义 UA 应与所选系统、内核保持一致。

如何重启窗口，按钮内的浏览器图标表示什么？

启动/停止按钮内的白色图标表示窗口使用的内核，Chrome 和 Firefox 会显示对应图标。点击右侧齿轮可重启、编辑、复制或删除窗口。重启仅对运行中的窗口可用，会正常关闭并重新打开同一独立数据目录；若浏览器没有正常退出，重启会取消，请手动关闭后再启动。Firefox 已提供测试接入：在内核管理导入 Windows x86_64 ZIP 或已解压目录，新建窗口或编辑窗口选择对应版本；i686 为32位，不支持。Firefox 使用单独的 Firefox 数据目录，切换内核不会迁移 Chrome 的登录数据。Chrome 插件不能用于 Firefox，请在浏览器中安装 Firefox 扩展。

如何删除导入插件？

在插件中心点击导入插件卡片上的「删除」，确认后解除全部窗口关联并删除插件文件。使用该插件的运行窗口需先停止；删除失败时保留列表与关联，可处理提示的问题后重试。内置三个插件可按窗口停用。

为什么窗口无法启动、节点 Timeout 或内核无法升级？

请先确认 Chrome 内核已经安装。代理节点会按系统设置中的当前连接栈测速和启动；普通 Clash 节点默认使用随包 Xray / sing-box 组合栈。若官网已有新版但界面未刷新，请打开升级面板并手动检查；点击「检查更新」会读取 GitHub 最新正式版；后台每周静默检查一次，不会自动下载安装。当前内核版本已等于或高于发布版本时，「更新并应用」显示「已是最新」并禁用，不会重复下载解压。内核下载持续失败时，请确认 Clash/FlClash 已开启系统代理，或使用页面顶部的「导入内核包／导入本地内核」。每个已安装内核独立显示，创建窗口默认选择已安装的最高版本。有关联窗口的内核无法删除，即使窗口已关闭也一样；先在窗口齿轮 → 编辑窗口中更换内核，保存后再删除。运行中的窗口需先停止再切换内核。程序管理目录内的闲置内核文件会删除，直接导入的外部原目录仅取消注册。

关闭主窗口后应用为什么仍在运行？

点击 Windows 关闭按钮会把 One Browser 隐藏到系统托盘，已打开的浏览器窗口不会被关闭。再次双击 OneBrowser.exe 可直接唤回主页，也可双击托盘图标。需要退出时，请右键托盘图标，选择“仅退出应用”或“退出应用与浏览器”。所有弹窗均可按 Esc 返回。

升级后仍看到旧界面，怎么办？

请先从系统托盘彻底退出 One Browser，再用新包中的 OneBrowser.exe 覆盖原程序并重新打开。在「系统设置」确认当前版本；不要同时运行不同目录下的旧程序。覆盖前备份 data 文件夹。

账号已关联，但窗口或账号卡片没有显示，怎么办？

点击窗口行中的账号图标，查看账号旁是否标记「已关联」；需要调整时重新选择或取消关联。账号卡片会显示关联窗口名称。同名旧账号可能无法自动确认归属，请手动重新关联后检查。

网站登录状态丢失或要求重新验证，怎么办？

请确认打开的是原来的窗口，未删除窗口数据或初始化系统，并且正常关闭过浏览器。账号关联用于管理分配，不会自动向网站登录。网站会话过期、主动退出或要求安全验证时，需要重新登录；密码需在浏览器提示时保存。备份时请退出应用和全部浏览器后复制整个 data 文件夹。
