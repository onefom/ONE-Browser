One Browser 1.8.10 Windows x64 便携候选版

使用方法：
1. 将整个文件夹解压到普通可写目录，不要直接在 ZIP 内运行。
2. 确保 Clash 或 FlClash 已开启“系统代理”。
3. 双击 OneBrowser.exe。
4. 进入“内核管理”，下载唯一的 fingerprint-chromium Windows x64 内核。
5. 创建窗口并启动。未手动选择导入节点时，默认使用 Windows 系统代理；系统代理未开启时自动直连。

本版新增：
- 系统日志页显示完整运行记录，支持 ALL、DEBUG、INFO、WARN、ERROR 五级筛选，并保留导出与清理功能。
- User Agent 推荐项统一为“Fingerprint-Chromium（推荐）”，选择自定义后可填写完整 UA，并真实应用到浏览器启动参数。
- 内核管理支持导入本地压缩包或已解压目录；系统设置新增清除缓存、加载配置、导出配置和保留内核的系统初始化。
- “查看配置”改为可用的二级详情弹窗，集中展示即将应用的系统、UA、语言、时区、窗口、指纹和隔离参数。
- 新建窗口下滑箭头与文字增大间距，遮罩颜色进一步增强。
- 窗口列表使用固定列宽，启动按钮在“启动 / 启动中 / 停止”切换时不再带动前方内容位移。
- 工作台重新排版，新增出口网络、代理、账号、扩展、隔离策略和工作区信息，整体保持紧凑小字号。
- 浏览器默认以 900 × 680 尺寸在屏幕左上角启动，不再默认占用半屏；旧版常见桌面尺寸在首次升级时自动迁移。
- 账号、账号关联窗口、窗口设置、浏览器界面设置、数据快照、日志以及 WebView2 本地状态统一保存在程序旁的 data 文件夹。
- 空白便携包不再自动读取 Windows AppData 中的旧窗口，避免删除旧版后窗口又重新出现。
- 新建窗口弹窗隐藏可视滚动条，底部增加“向下滑动查看更多”渐变提示，取消和创建窗口按钮始终固定在底部。
- 下滑箭头与提示文字改为上下居中排列，并增强浅紫色遮罩的可见度。
- 内核升级红点只在已安装版本确实低于当前版本时显示；无内核时显示“当前无内核，请先下载”。
- 多个窗口配置同时启动时，每个配置强制打开独立的 fingerprint-chromium 窗口，不再把第二个窗口交给第一个浏览器。
- 启动工作台改为紧凑的小字号指纹信息表，显示完整 User Agent、语言、时区、地理位置策略、分辨率、字体指纹和 WebRTC 等信息。
- 首标签“工作台”显示窗口、账号、代理、出口 IP、系统、语言、时区、内核版本和窗口尺寸；第二标签为 Google。
- 删除旧 Ant 指纹检测书签并关闭默认浏览器提示。
- AdGuard、篡改猴、Google 翻译在后台按需下载，不再阻塞窗口启动；准备完成后自动加载。
- 操作日志支持导出、清理30天以上和清空当前列表。
- Chrome 应用商店和 Google Drive 均在已启动的 One Browser 窗口内打开。
- 最新账号/窗口数据快照保存在 data/backups/one-browser-data.json。
- 代理删除按钮改为 X，窗口筛选按钮移除外描边。
- Windows 标题栏、程序文件和系统托盘统一使用 One Browser O 图标。
- 工作台把出口 IP 与网络位置合并显示。
- Chromium 扩展页默认开启开发者模式，内置插件安装后默认启用。
- 优化侧栏账号头像和更多按钮间距，并取消账号列表密码预览。
- 帮助中心精简顶部内容、移除右侧搜索和嵌套滚动条，并显示当前版本。
- 全局界面优先使用苹方字体；Windows 无苹方时自动回退微软雅黑。

Google Drive 说明：
当前版本会在受管浏览器内打开 Google Drive 登录页，并导出 OneBrowser-data.zip 供上传；未内置任何 Google OAuth 客户端密钥，因此不会伪装成已完成 API 自动上传。

从 1.8.1 / 1.8.2 升级：
1. 先关闭 One Browser，并备份旧文件夹。
2. 如需保留已经下载的内核和窗口资料，可将旧版 chrome 与 data 文件夹复制到新版目录；不要在程序运行时复制。
3. 1.8.10 不会自动读取 AppData。需要保留资料时，请复制旧版整个 data 文件夹；需要全新开始时，直接使用本包的空 data 文件夹。
4. 本交付包本身仍为空数据包，不包含你的账号、节点、日志、缓存或浏览器内核。

清除 1.8.5 遗留窗口：
1. 完全退出 One Browser，并在任务管理器确认 OneBrowser.exe 已结束。
2. 只清除窗口列表：删除当前便携目录下的 data/webview2 文件夹，再启动 1.8.10。
3. 全部恢复空白：保留 data/README.md，删除 data 内其他文件和文件夹，再启动 1.8.10。
4. 如仍运行 1.8.5，还需同时删除 %APPDATA% 下的 OneBrowser.exe、one-browser.exe 和 One Browser.exe 同名目录，否则 1.8.5 会再次导入。

首次测试重点：
- 右上角关闭按钮能否正常退出。
- 最大化以及拖动窗口尺寸时是否流畅。
- 不导入节点时能否自动使用 Clash/FlClash 当前节点。
- 导入节点后能否选择、启动和删除；删除当前节点后应恢复系统代理。
- 内核页是否只显示 fingerprint-chromium。

隐私说明：
本包不包含任何账号、订阅节点、日志、缓存、用户数据库或浏览器内核。
日常备份或搬移时请复制整个 data 文件夹；其中可能包含账号密码、Cookie 和浏览器会话，请妥善保管。

测试边界：
本包已在 Linux 构建环境完成前端构建、Go 针对性测试、静态检查、模拟点击和 Windows x64 交叉构建，但尚未在真实 Windows 机器上运行验证。
