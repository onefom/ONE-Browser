# 界面截图

本目录为 GitHub 首页使用的六张截图。首页采用两列三行排版，点击图片查看大图。图片按原比例展示，不固定显示高度。

| 文件 | 内容 |
| --- | --- |
| `01-windows-light.png` | 窗口管理 · 浅色 |
| `02-create-window.png` | 创建窗口 |
| `03-kernels.png` | 内核管理 |
| `04-proxies.png` | 代理管理 |
| `05-settings.png` | 系统设置 |
| `06-dual-kernel-dark.png` | 双内核运行 · 深色 |

代理订阅信息，以及双内核运行截图中的出口 IP、本地地址和工作区标识已作隐私遮盖。
